Your morning starts with context, not archaeology

November 9, 2026 · 4 min read

Coming in L2Cache 2.0. The Today page is part of the Developer Home, arriving in 2.0, which is coming soon. The App Store has version 1.4.6 today.

The first half hour of a working day often goes on digging. Which branch was I on? What did I ask the agent last night, and did it finish? Did the tests pass before I left? Is anything sitting unpushed? You scroll through terminal history, reopen agent sessions and run git status in three repositories before writing a line of code.

L2Cache's Today page answers those questions before you ask them. It's the first page of the Developer Home, and it's built from what's already on your Mac: your coding-agent sessions, your Git repositories and your commands.

Pick up where you left off

The main card lists the work in progress, one row per feature, newest first. If nothing has happened yet today, it shows Where you left off: the features you were working on before, labelled with the day you last touched them.

Each row gives you what you need to carry on:

  • A session recap: what you asked, the agent's last update, and the latest commit, with a link to it on GitHub when the branch is pushed.
  • The context strip: how big the agent's session has grown, and whether its prompt cache is still warm. A warm session says how long it's cheap to continue. A cold one says the next message would reload everything, and offers Start fresh with handoff instead.
  • Continue This Session: copies the command to resume that exact session, ready to paste into your terminal.
  • Recap › opens the full session, and the branch chip shows which branch the work is on.

The rows come from short summaries your coding agents write as they work. With L2Cache's hooks connected, Claude Code and Codex end each turn that edited files with one line: the feature, what changed, and the next step. L2Cache checks each line against the file changes it recorded. Work without a summary still shows up, built from the raw edits. See how Your Day and the work summaries work.

Why the cache state matters in the morning

A session you left overnight has almost certainly gone cold. Its prompt cache expired hours ago, so your first message would reload the whole conversation at the most expensive rate. The card tells you this before you type, and a fresh session with a short handoff is usually the cheaper way back in. The details are in why resuming a cold Claude Code session costs more and starting a fresh session without losing context.

The numbers at the top

A row of stats gives you the shape of the day at a glance:

  • Projects active recently.
  • Commits you've made.
  • Need attention: how many loose ends are waiting, from the card below.
  • Claude Code and Codex usage: how much of your weekly limit is left and when it resets, or roughly how many days until you run out at your current pace.

Needs attention

Beside your work, a Needs attention card gathers the loose ends from every project:

  • The last test or build run failed.
  • Commits that are only on this Mac.
  • Branches waiting for review: pushed but not merged.
  • Branches idle for 30 days or more, and groups of related branches.

Long details fold to two lines and expand on click. If something isn't urgent, dismiss it for a week and it gets out of the way. When nothing needs you, the card says All clear.

Your other projects

Below, Other active projects has a card for each project you've touched lately: the branch, what you were doing or the next step, and when you were last there. Each card can open the project in your editor or in Terminal, or copy the command to resume its latest agent session. A small bar chart of the past seven days shows where your time went, in the same project colours L2Cache uses everywhere.

Standup and Weekly Brief

  • Copy standup writes a Yesterday / Today / Blockers standup from your sessions and Git history, ready to paste into Slack. It works with AI off. With AI on, your provider rewrites it and may only use the facts it's given.
  • Weekly Brief opens a summary of your week: what got done and where to pick up. It appears by itself on Mondays, and the button toggles it any day.

Sharing your screen in a standup? Presentation mode masks project names, paths, prompts and commands while keeping the layout, so you can show the page without showing the work.

Setting it up

The first time you open Today, a short checklist asks for two things: your projects folder, so L2Cache can read your repositories, and your coding-agent folders, so it can read your sessions. After that the page fills itself in. Connecting L2Cache's hooks adds the work summaries and the live cache state.

All local

Everything on Today is read from your Mac: session files, the .git folders of your repositories, and L2Cache's own history. L2Cache never runs Git, and nothing is sent anywhere. The usage figures come from the limits Claude Code and Codex already report to your terminal.

The short version

  • Today shows each feature in progress with what you asked, what the agent did, the last commit and the next step.
  • Each row shows whether the agent's cache is still warm, and copies the command to resume the session.
  • Needs attention gathers failed runs, unpushed commits and unmerged branches across projects.
  • Copy standup and the Weekly Brief turn the same facts into something you can paste.
