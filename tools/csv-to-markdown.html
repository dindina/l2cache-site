Markdown Table Syntax Quick Reference

Markdown tables use vertical pipes (|) to separate columns and hyphens (-) with optional colons (:) to define alignment:

  • | :--- | : Left aligned column
  • | :---: | : Center aligned column
  • | ---: | : Right aligned column
