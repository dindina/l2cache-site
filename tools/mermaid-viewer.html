Frequently Asked Questions

Is my diagram syntax or architecture sent to a server?

No. The L2Cache Mermaid Viewer runs entirely in your local browser runtime. Zero HTTP requests, zero cloud tracking, and zero database logging. Test by enabling Airplane Mode above.

How do I copy the diagram into Figma or Markdown?

Click the 📋 Copy SVG button in the toolbar. You can paste vector SVGs directly into Figma, Sketch, or Adobe Illustrator as native editable shapes. For GitHub or Obsidian, copy the Mermaid snippet directly.

Can I share diagrams with my teammates without saving to a database?

Yes! Click the 🔗 Share button to generate a URL with your diagram code encoded directly in the URL hash fragment. Anyone opening the link will see the exact same diagram rendered locally in their browser.

What diagram formats are supported?

Flowcharts (graph TD / LR), Sequence Diagrams (sequenceDiagram), Class Diagrams (classDiagram), State Machines (stateDiagram-v2), ER Diagrams (erDiagram), User Journeys (journey), Git Graphs (gitGraph), Gantt Charts (gantt), Mindmaps (mindmap), and Pie Charts (pie).
