Warnings L2Cache tells you first

A heads-up before the cache goes cold.

  • Cache expiring soon. A menu-bar badge and a row at the top of the quick panel when a Very heavy session's cache is about to expire, plus a macOS notification if you turn it on.
  • Keep warm. For a Heavy session on a 1-hour cache, L2Cache offers a short heartbeat you can send to keep it warm.
  • Cold resume guard. Resume a session whose cache has expired and the terminal warns you before your first message, then holds that costly message once. Type /clear to start fresh with a handoff, or press ↑ and Return to send it anyway.

For Claude Code. Terminal warnings need L2Cache hooks turned on. Everything here is on by default except macOS notifications, and each can be turned off in Settings.

Frequently asked questions

What is L2Cache?

L2Cache is developer memory for Mac. It connects your projects, coding-agent sessions, terminal history, Git activity, screenshots and clipboard content, so when you come back to your Mac you can see where you left off and resume the work.

Is L2Cache a clipboard manager?

It includes one. L2Cache started as a clipboard manager and still has searchable clipboard history with smart actions, opened with the ⌥Space quick panel. Version 2.0 adds the Developer Home, which brings clipboard, terminal, Git and coding-agent history together by project.

Which coding agents does L2Cache read history from?

L2Cache reads local session history from Claude Code, Codex, GitHub Copilot, Grok Build and Google Antigravity. Available details and live-continuity features vary by agent.

Can I resume a Claude Code or Codex session from L2Cache?

Yes. L2Cache generates the resume command for supported sessions and can open it in your terminal. The agent's command-line tool and the original session must still be installed and available on your Mac.

Can my coding agents use L2Cache directly?

Yes. Connect the L2Cache MCP server and agents such as Claude Code, Codex, Cursor and Antigravity can search your clipboard history, screenshots and saved folders themselves. Optional hooks for Claude Code, Codex, GitHub Copilot and Grok Build share your recent clipboard items and the previous session's context with each new session. Agents can also look up earlier sessions' fixes, decisions and work summaries. Both run on your Mac, and sensitive items are never shared.

Where is my history stored?

Your history is stored locally in L2Cache's database on your Mac. Smart features use on-device Apple Intelligence where your Mac supports it, a local Ollama model, or rule-based processing.

Does L2Cache help with coding-agent token use?

Yes, for Claude Code and Codex. L2Cache shows each session's context size and whether its prompt cache is still warm, warns before a heavy session's cache expires, and can stop the first message to a Claude Code session whose cache has gone cold, so you can start fresh with a handoff instead of reloading the whole context.

How much does L2Cache cost?

L2Cache is a free download from the Mac App Store with a 15-day Pro trial. Pro is a one-time unlock with no subscription.
