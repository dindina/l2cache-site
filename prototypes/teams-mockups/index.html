For each developer · in the terminal, through agent hooks

1 · Cold Resume Guard

Stops the expensive message, once.

Resuming a session whose cache expired means the next message re-writes the whole context — 12× to 80× the cost of a warm turn, depending on the model. L2Cache says so on resume, pauses that first message once, and points to the cheaper path.

Mac app: Cold Resume Guard (Sprint 48).

~/auth-service — claude
~/auth-service $ claude --resume Resumed "Migrate auth to session tokens" · last active 9 h ago SessionStart:resume says: Cold cache at 09:12 — this session's cache expired 9 h ago. Your next message reloads 74k tokens (≈ 20× a warm turn). Cheaper: type /clear — L2Cache starts a fresh session with this session's handoff. Or just send your message to continue as is. > add refresh-token rotation UserPromptSubmit operation blocked by hook: L2Cache stopped this message so it doesn't reload 74k tokens. • /clear — fresh session with the handoff (recommended) • Press ↑ and Enter to send it anyway (you won't be stopped again in this session) Original prompt: add refresh-token rotation
2 · Fresh start with handoff

/clear, and the agent already knows where you were.

The new session starts empty and receives a short handoff: what's done, what's pending, the last exchange, and steps that may already be finished — so nothing is redone.

3 · Context budget

A nudge when a session gets heavy.

Every request re-reads the whole context. L2Cache tells you in the terminal when a session crosses a heavy threshold — shown only to you, costing the model nothing — and once more before you walk away from a very heavy one.

Mac app: Context Budget terminal nudges.

4 · Team memory · new for Teams

“Someone on the team already fixed this.”

Before debugging, the agent asks L2Cache whether this error was solved before — and gets the cause, the fix, the files and the test that proved it, even when a teammate solved it with a different agent.

New for Teams: captured by the collector's hooks, shared only after the developer approves each fix.
