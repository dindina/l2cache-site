Stop Writing Mock Data by Hand: Generate JSON from SQL using AI

Setting up a testing environment is the most tedious part of building any new feature.

You write a beautiful, perfectly normalized CREATE TABLE SQL statement for your new "User Profile" feature. Then, you realize you need to test the frontend UI. Now you have to sit there and manually type out a massive JSON array with fake names, fake emails, and fake timestamps just to see if your React component renders correctly.

The standard workflow usually involves:

  1. Copying the SQL schema.
  2. Opening a browser.
  3. Loading up ChatGPT or Claude.
  4. Writing a prompt like, "Generate 5 rows of mock JSON data for this schema."
  5. Copying the result back to your IDE.

It's a massive context switch that derails your focus.

The AI-Powered Clipboard

What if your clipboard could just do the translation for you?

With L2Cache, I built a clipboard manager that acts like a local, scriptable AI agent. It allows you to run "Custom Smart Actions" directly on whatever text is currently sitting in your clipboard.

Here is the new workflow:

  1. Highlight your SQL schema in your IDE and hit Cmd + C.
  2. Hit Option + V to bring up the Smart Paste menu.
  3. Select "Generate Mock JSON".
  4. Paste the fully populated JSON array directly into your code.

Behind the scenes, L2Cache takes the SQL schema you copied, wraps it in a predefined prompt, sends it to an LLM (either a local model via Ollama or a cloud model), and streams the resulting JSON back into your clipboard buffer.

No browser. No context switching. Just instant mock data formatted exactly how you need it.

Because L2Cache allows you to write your own Custom Actions using Python, Ruby, or Bash, you can tweak the generation prompt to output CSVs, XML, or even Swift structs based on that same SQL block.
