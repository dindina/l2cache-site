How to view and search Mac command history

The Mac terminal remembers what you type, but finding that one curl command or ssh flag from last week is harder than it should be. Here is how to use the built-in history, how to fix its worst defaults in two minutes, and what to do when you need to know where a command ran and whether it worked.

Short answer

Type history to list recent commands, or press Ctrl + R and type part of one to search. Zsh keeps them in ~/.zsh_history. Add setopt SHARE_HISTORY to ~/.zshrc so every tab sees the same history.

Zsh history doesn't store the folder, git branch or exit code. L2Cache records all of that for every command, on your Mac.

Updated November 2026 · By the team behind L2Cache

If you spend any time in the macOS Terminal (or iTerm2, Warp or Ghostty), you know the feeling: you finally get a Docker build or an ffmpeg script working with ten different flags. A week later you need it again, and the flags are gone from your head.

macOS gives you three ways to get it back. Then we'll look at where they stop.

1. Use the history command

The simplest way to see what you've typed recently is the shell's own history list.

  1. Open your Terminal app.
  2. Type history and press Return.

You get a numbered list of your recent commands. To run one again, type an exclamation mark and its number (for example !142) and press Return. !! repeats the last command.

To search the list, pipe it into grep: history | grep docker. In zsh, history 1 shows the whole file, not just the last 16 entries.

2. Reverse search (Ctrl+R)

Scrolling a list is slow. If you remember any piece of the command, reverse search is faster.

  1. In your terminal window, press Ctrl + R.
  2. Your prompt changes to (reverse-i-search)`':
  3. Type part of the command you remember.
  4. The shell shows the most recent match. Press Ctrl + R again to step back to older matches.
  5. Press Return to run it, or the right arrow key to edit it first.

3. Fix zsh's history defaults

Most "my command is gone" moments come from three zsh defaults: history is written only when a shell exits, each tab reads it only when it starts, and the file is capped. Add this to ~/.zshrc and open a new tab:

HISTFILE=~/.zsh_history
HISTSIZE=100000          # lines kept in memory
SAVEHIST=100000          # lines kept in the file
setopt SHARE_HISTORY     # every tab writes and reads history as you go
setopt EXTENDED_HISTORY  # save a timestamp and duration with each command
setopt HIST_IGNORE_SPACE # a command that starts with a space isn't saved
setopt HIST_IGNORE_DUPS  # don't save the same command twice in a row

Now a command you run in one tab shows up in Ctrl + R in every other tab, and old commands stop falling off the end. With EXTENDED_HISTORY, history -i 1 shows when each one ran. HIST_IGNORE_SPACE is the one to remember for secrets: put a space before export API_KEY=… and it never reaches the file.

Where the built-in terminal history stops

Even tuned, ~/.zsh_history is a text file of command lines. It can't answer the questions you usually have a week later:

  • Where did I run it? There's no working folder, so npm run build from five projects all look the same.
  • Did it work? There's no exit code. The broken version and the one that finally worked sit side by side.
  • Which branch was I on? Git context isn't recorded.
  • What did my coding agent run? Commands that Claude Code or Codex run go through their own shells, not your history file.
  • Secrets sit in plain text. Anything you didn't prefix with a space, such as a token in a curl header, is stored as typed.
The gap

Shell history remembers what you typed. A week later you need where it ran, whether it worked, and the other commands from that same afternoon.

Frequently asked questions

How do I see my command history on a Mac?

Open Terminal and type history. It prints a numbered list of your recent commands. Type ! followed by a number (for example !142) to run one again.

Where is the terminal history file located on Mac?

Zsh, the default shell since macOS Catalina, saves history to ~/.zsh_history. Bash uses ~/.bash_history. Terminal.app can also keep a separate history per window under ~/.zsh_sessions.

How do I search my previous commands in Mac terminal?

Press Ctrl + R to open reverse-i-search, then type part of the command. Press Ctrl + R again to step back through older matches, Return to run the match, or the right arrow key to edit it first.

Why don't commands from one Terminal tab show up in another?

By default zsh writes history to the file when a shell exits, and each tab reads the file only when it starts. Add setopt SHARE_HISTORY to ~/.zshrc so every tab writes and reads history as you go.

Can I see which folder a command ran in, or whether it failed?

Not from zsh history. With setopt EXTENDED_HISTORY zsh stores a timestamp and duration, but not the folder, git branch or exit code. L2Cache records all four for every command through a small shell hook.

Does L2Cache record commands my AI coding agent ran?

Yes. Commands run by coding agents such as Claude Code and Codex appear in L2Cache's Terminal history under an Agents filter, separate from the commands you typed yourself.

How does L2Cache compare to terminal history tools like Atuin or McFly?

Atuin and McFly replace your shell's Ctrl + R search inside the terminal, and Atuin offers optional sync. L2Cache is a Mac app: it records commands with their folder, branch and exit code, keeps them next to your clipboard history and coding-agent sessions, and searches all of them locally with no sync.
