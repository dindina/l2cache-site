Session discovery and resuming work

L2Cache helps with local session discovery and transcript search. When you find the conversation, use the supported resume workflow to continue it in Claude Code. The exact resume command and transcript locations can change with Claude Code releases; our guide explains the current local files and CLI options.

Agent history can also include token telemetry and prompt/cache information where those fields are available in the local session data. It is a view of the records produced by the tools, not a claim that every session exposes the same metrics.

Local developer history, together

Claude Code sessions are only one part of a debugging trail. You might also need the kubectl command you ran or the cURL request you copied. L2Cache brings supported Claude Code and Codex history together with terminal and clipboard history. The local records stay on your Mac; L2Cache does not turn them into a cloud search service.
