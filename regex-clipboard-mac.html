Regex Pattern Matching for Mac Clipboard

Why settle for basic text search? L2Cache lets you filter your clipboard history using powerful Regular Expressions (Regex) directly from your menu bar.

As a developer, you often copy hundreds of snippets a day — log lines, UUIDs, IP addresses, JSON blobs, and API tokens. When you need to find a specific clip from hours ago, typing a simple keyword isn't always enough.

What if you need to find all the IP addresses you copied today? Or every AWS Access Key? With L2Cache, you can use standard Regex syntax to instantly filter your massive clipboard history.

The Power of "History Grep"

L2Cache brings the power of terminal grep to your Mac's clipboard. By typing a Regex pattern into the search bar, L2Cache natively evaluates your local SQLite clipboard store and highlights the exact matches in milliseconds.

Key benefits:

  • Standard Syntax: Supports standard PCRE/Swift Regex syntax. Just type your pattern and see the results.
  • Instant Filtering: The native SQLite FTS5 backend ensures that even if you have 10,000 clips, regex filtering is lightning fast.
  • Complex Queries: Combine full-text search with regex patterns to narrow down exactly what you're looking for.

Frequently Asked Questions

Is the regex search case-sensitive?
By default, regex searches in L2Cache are case-insensitive to help you find data faster, but you can enforce case sensitivity using standard regex flags.
Do I need an active internet connection to use Regex?
No. All pattern matching is evaluated entirely locally on your Mac using native macOS frameworks. Your clipboard data never leaves your machine.
Can I extract specific capture groups?
L2Cache uses the regex pattern to filter the clips that match. It currently returns the entire clip that contains the match, highlighting the matched text.
